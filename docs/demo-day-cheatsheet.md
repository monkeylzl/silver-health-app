# Silver Health Demo Day Cheatsheet

> 适用场景：
> - 临上场前 30 秒看一眼；
> - 需要别人临时代讲；
> - 不想翻长讲稿，只想知道“按什么顺序点、每页说一句什么”。

---

## 0. 先做 1 件事

```bash
pnpm demo:ready
```

通过后再开讲；这时 demo 数据和 README / 首页 / 提词材料的关键口径都会一起过检查。

如果临时想手动补查一眼：

```bash
pnpm check:demo-copy
```

它不只是在查文案，还会一起校验 cheatsheet 自己是否已经补到 `check:demo-copy` / `demo:ready` 这套接手说明，以及 `demo:ready` 最终那句 **“现在可以开 API / Web，并优先从首页 / 开讲。”** 有没有漂移。

**直接记结论：现在可以开 API / Web，并优先从首页 / 开讲。**

如果还想多确认一眼，只抽查两页：
- `/elder/home`
- `/family/dashboard`

顶部优先看到：**当前接入：真实 API**

---

## 1. 最短演示顺序

1. `/elder/profile` 老人建档
2. `/elder/home` 今日任务
3. `/elder/metrics` 指标录入
4. `/elder/medication` 用药提醒
5. `/family/dashboard` 家属看板
6. `/family/report` 家属周报
7. `/family/bind` 只在被问到“家属怎么关联”时再补

一句话记忆：

> **老人负责日常执行，家属负责远程查看。**

---

## 2. 每页只讲 1 句

### `/elder/profile`
> 先建档，后面所有动作都围绕这位老人展开。

### `/elder/home`
> 老人当天该做什么集中在这里，可以现场完成 1 项任务。

### `/elder/metrics`
> 补一条血压或血糖，数据会直接流到家属侧摘要和周报。

### `/elder/medication`
> 再补一条提醒，把长期管理场景补完整。

### `/family/dashboard`
> 家属不用翻原始记录，也能快速看懂老人今天怎么样。

### `/family/report`
> 周报不是堆数据，而是把这一周沉淀成可理解的回顾。

### `/family/bind`
> 这是关系建立页，通常最后补，不要一上来就讲。

---

## 3. 现场操作分层

### 建议现场操作
1. 在 `/elder/profile` 保存 1 次建档；
2. 在 `/elder/home` 勾掉 1 个任务；
3. 在 `/elder/metrics` 新增 1 条指标。

### 优先只讲即可
- `/elder/medication`
- `/family/dashboard`
- `/family/report`

### 只在被问到时再补
- `/family/bind`

一句话记住就是：**真正动手只做 3 个动作，后面页面优先只讲即可。**

---

## 4. 30 秒收尾话术

> 当前阶段重点不是堆很多功能，而是把一条主链路打顺：建档、今日任务、指标录入、用药提醒、家属查看已经能串成完整 demo。

如果还要再短一点：

> **老人这边完成日常动作，家属那边直接看到摘要和回顾。**

---

## 5. 忘词时就念这 6 句

1. 先建档，后面都围绕这位老人。
2. 今日任务承接当天动作。
3. 录一条指标，后面家属侧就有新内容。
4. 用药提醒补齐长期管理。
5. 家属看板看今天。
6. 家属周报看这一周。
